# Если что-то не работает

| Что видно | Почему | Что сделать |
|---|---|---|
| `python не является внутренней или внешней командой` | Python не установлен или не добавлен в PATH | Переустановите Python с галочкой **Add Python to PATH**, перезапустите компьютер |
| `выполнение сценариев отключено в этой системе` | Windows запрещает запуск скриптов PowerShell | Запускайте именно так, как написано: `powershell -ExecutionPolicy Bypass -File ...` |
| `No module named fastapi` | Библиотеки не установлены | Откройте `backend/setup.cmd`, затем `START.cmd` |
| Порт 8000 или 5500 занят | Сервер уже запущен в другом окне | Нажмите Ctrl+C в окне прежнего сервера. Если запущен весь проект, отдельно запускать эти же серверы не нужно |
| «Бэкенд недоступен. Запустите backend/start.cmd…» | Работает только фронтенд | Откройте `backend/start.cmd`, дождитесь надписи ГОТОВО, обновите сайт на http://localhost:5500 |
| На http://localhost:8000 ответ `Not Found` | Бэкенд запущен отдельно и раздаёт только API | Откройте сайт на http://localhost:5500, документацию API — на http://localhost:8000/docs |
| Сайт открылся, но всё старое (например, старый логотип) | Браузер показывает сохранённую копию | Нажмите **Ctrl + F5** (обновление без кэша) |
| Вместо фото — тёмные плашки с надписью BLIND BARBER | Файлы фото не скопировались вместе с проектом | Это нормально: так задумано. Фото кладутся в `frontend/assets/img/...` (список папок — в [05-логотип-иконки-фото](../04-сайт-фронтенд/05-логотип-иконки-фото.md)) |
| «Рядом со мной» не работает | Браузер не дал доступ к местоположению | Разрешите доступ к геопозиции в адресной строке браузера |
| После изменений в данных всё сломалось | Испорчена база данных | Остановите сервер, удалите `backend/data/barber.db`, запустите снова |
| Анимаций нет | В Windows включено «Показывать анимацию» = выкл. | Так и задумано для людей, которым анимации мешают. Включите: Параметры → Специальные возможности → Визуальные эффекты |
| Переход между страницами без эффекта | Браузер старый или Firefox | В Chrome / Edge / Safari 18 будет плавный переход, в остальных — упрощённый |

## Где смотреть ошибки

- **Ошибки сервера** — в окне PowerShell, где запущен сервер (красный текст, слово `Error`).
- **Ошибки страницы** — в браузере нажмите `F12` → вкладка **Console**.
