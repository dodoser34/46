# Как запустить сайт на компьютере

Если вы получили проект из GitHub или ZIP и начинаете с нуля, сначала прочитайте [полную пошаговую инструкцию](../../ЗАПУСК.md). Там есть ссылки на скачивание Python, установка, получение исходников и объяснение отсутствующих `.env`, `.venv` и базы.

Сайт работает на вашем компьютере как маленький «интернет внутри компьютера»:
фронтенд показывает страницы на `http://localhost:5500`, а бэкенд обрабатывает данные на `http://localhost:8000`.

> `localhost` значит «этот компьютер». Никто, кроме вас, сайт по этому адресу не увидит.

## Что должно быть установлено

| Программа | Зачем | Где взять |
|---|---|---|
| **Python 3.11** или новее | На нём работает сервер | python.org → Downloads. При установке поставьте галочку **Add Python to PATH** |
| Браузер (Chrome, Edge, Firefox) | Открыть сайт | Обычно уже есть |

Больше ничего не нужно: ни отдельной базы данных, ни Node.js. База данных — это один файл, он создастся сам.

## Самый простой запуск: двойной щелчок

1. Откройте папку проекта `димаш` в проводнике.
2. Дважды нажмите **START.cmd**.
3. Оба сервера запустятся автоматически.
4. При первом запуске дождитесь установки библиотек (нужен интернет), затем надписи **ГОТОВО**.
5. Откройте **http://localhost:5500** в браузере.

Окно оставляйте открытым. Остановка обоих серверов — **Ctrl+C**.
При следующем запуске снова откройте `START.cmd`.

## Фронтенд и бэкенд по отдельности

| Что открыть двойным щелчком | Что работает | Что открыть в браузере |
|---|---|---|
| **frontend/start.cmd** | Страницы, стили, JavaScript | http://localhost:5500 |
| **backend/start.cmd** | API, база данных, авторизация, каталог, записи и заказы | http://localhost:8000/docs |

Откройте оба файла, если нужен работающий сайт. Получатся два окна: можно остановить фронтенд, оставив бэкенд включённым, и наоборот.
В режиме `backend/start.cmd` сервер на 8000 раздаёт только API; сайт открывается на 5500.
Без бэкенда страницы загрузятся, но данные и вход будут недоступны. Для запросов данных появится сообщение «Бэкенд недоступен. Запустите backend/start.cmd…».

Фронтенд автоматически пересылает запросы `/api` на `127.0.0.1:8000`. Адрес API в JavaScript менять не нужно.
Правки HTML/CSS/JS видны после обновления страницы; бэкенд перезапускается при изменении Python-файлов.

## Запуск из терминала

Откройте PowerShell в папке проекта и выберите команду:

```powershell
.\START.cmd
# Или в двух отдельных окнах:
.\backend\start.cmd
.\frontend\start.cmd
```

Установка зависимостей запускается автоматически для бэкенда, если их ещё нет.
Для переустановки или установки библиотек тестирования откройте **backend/setup.cmd**.
Существующие настройки `backend/.env` сохраняются.

Если стандартные порты заняты, можно выбрать другие:

```powershell
.\backend\start.cmd --backend-port 8001
# В другом окне, с тем же портом API:
.\frontend\start.cmd --backend-port 8001 --frontend-port 5501
```

В этом примере сайт откроется на http://localhost:5501, API — на http://localhost:8001/docs.

## Команды из scripts

Команды `powershell -ExecutionPolicy Bypass -File scripts/setup.ps1`, затем
`powershell -ExecutionPolicy Bypass -File scripts/run.ps1` по-прежнему работают:
они используют тот же общий запуск: сайт на **http://localhost:5500**, API на **http://localhost:8000/docs**.
Выбирайте один способ запуска, чтобы не занимать одни порты дважды.

## На Mac или Linux

```bash
python3 scripts/dev/launcher.py all
```

```bash
python3 scripts/dev/launcher.py backend
# В другом терминале:
python3 scripts/dev/launcher.py frontend
```

## Через Docker (если установлен)

```bash
docker compose up -d --build
```

Сайт откроется по тому же адресу `http://localhost:8000`. Подробнее — в [08-деплой](../08-деплой/).

## Как начать «с чистого листа»

Все записи, заказы и пользователи хранятся в файле `backend/data/barber.db`.
Чтобы вернуть сайт к исходным демо-данным: остановите сервер (`Ctrl + C`), удалите этот файл
и запустите сервер снова — база создастся и заполнится заново.
