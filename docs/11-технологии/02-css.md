# CSS: оформление и адаптивность

[Оглавление](README.md) · [Далее: JavaScript](03-javascript.md)

## Что делает CSS

CSS задаёт цвет, шрифт, размер, расстояния и расположение элементов. Одно правило может применяться ко всем элементам с нужным классом. Оно состоит из селектора и блока свойств:

```css
.page-title {
  color: var(--text);
  margin-bottom: 16px;
}
```

Здесь `.page-title` — селектор класса, `color` — свойство, `var(--text)` — его значение. Это учебный пример: действующие правила ищите в файлах проекта.

## Карта стилей проекта

Точка входа — [main.css](../../frontend/assets/css/main.css). Он подключает остальные таблицы через `@import`.

| Файл или папка | Назначение |
|---|---|
| [base.css](../../frontend/assets/css/base.css) | Цвета, шрифты, основные переменные, базовые элементы |
| [components.css](../../frontend/assets/css/components.css) | Кнопки, поля, карточки и повторяющиеся детали |
| [layout.css](../../frontend/assets/css/layout.css) | Шапка, подвал и общие блоки |
| [pages](../../frontend/assets/css/pages/) | Оформление конкретных страниц |
| [layers.css](../../frontend/assets/css/layers.css) | Слои фотографий и сцен |
| [ambient.css](../../frontend/assets/css/ambient.css) | Фоновое оформление |
| [motion.css](../../frontend/assets/css/motion.css) | Анимации и переходы |
| [responsive.css](../../frontend/assets/css/responsive.css) | Правила для разных размеров экрана |

Порядок важен. При одинаковой специфичности правило, подключённое позже, может заменить более раннее. Специфичность учитывает тип селектора: например, `#id` сильнее `.class`, а класс сильнее имени тега. Не исправляйте каждый конфликт через `!important`: найдите источник правила во вкладке Styles браузера.

## Переменные оформления

Реальные переменные из `base.css`:

```css
:root {
  --bg: #0b0a09;
  --text: #f2ece3;
  --accent: #c08a5b;
  --accent-hover: #d39d6c;
  --radius: 14px;
}
```

`:root` выбирает корневой элемент документа. Значение переменной читается через `var(--accent)`. Если нужно изменить медный акцент всего сайта, начните с этой переменной и связанных состояний наведения. Проверьте, что текст по-прежнему хорошо читается на новом фоне.

## Блочная модель

У элемента есть содержимое, внутренние отступы `padding`, граница `border` и внешние отступы `margin`. В проекте применяется:

```css
*, *::before, *::after { box-sizing: border-box; }
```

Поэтому заданная ширина включает внутренние отступы и границы. `margin` остаётся снаружи. Это облегчает расчёт ширины карточек и форм.

## Flexbox и Grid

Flexbox удобно использовать для одного ряда или колонки: группа кнопок, строка цены и статуса. Grid подходит для строк и столбцов: каталог, календарь, сетка товаров.

Учебные примеры:

```css
.actions {
  display: flex;
  gap: 12px;
  flex-wrap: wrap;
}
.example-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 24px;
}
```

`gap` задаёт промежутки между элементами. `flex-wrap` разрешает перенос. `1fr` — доля свободного пространства Grid; `minmax(0, 1fr)` позволяет колонке сжиматься, когда внутри длинный текст.

## Состояния элементов

Селектор `.chip.active` означает «элемент одновременно с классами `chip` и `active`». `.chip .active` с пробелом означает вложенный элемент — это другое правило.

`button:hover` применяется при наведении, `input:focus-visible` — при видимом фокусе, `button:disabled` — к выключенной кнопке. Не убирайте видимый фокус без замены: пользователь должен понимать, какой элемент выбран клавиатурой.

JavaScript меняет классы `active`, `hidden`, `invalid`, а CSS определяет, как соответствующее состояние выглядит. Например, выбранный шаг записи и активная вкладка кабинета оформляются через классы.

## Адаптация под экран

В `responsive.css` есть правила для ширин 1100, 900, 640 и 380 пикселей, а также для больших экранов. Учебный пример:

```css
@media (max-width: 640px) {
  .example-grid { grid-template-columns: 1fr; }
}
```

Оно действует только при ширине окна не больше 640 CSS-пикселей. `px` — CSS-пиксель; `%` зависит от контекста; `rem` связан с размером корневого шрифта; `vw` — доля ширины окна. `clamp(16px, 4.2vw, 104px)` в переменной `--gutter` задаёт плавный отступ с нижней и верхней границей.

На телефоне проверяйте не только сетку: длинные названия, ширину полей, доступность меню, кнопки, модальные окна и отсутствие горизонтальной прокрутки.

## Анимации

`transition` плавно меняет свойство при смене состояния, `@keyframes` описывает анимацию по кадрам, `transform` перемещает или масштабирует элемент. Не все свойства полезно анимировать: изменение геометрии может вызывать перерасчёт расположения страницы.

Проект учитывает `prefers-reduced-motion: reduce` в `responsive.css`, `motion.css` и JavaScript. Пользователь, отключивший движения в системе, должен сохранять доступ к содержимому и действиям.

## Как менять оформление

1. Выберите элемент в браузере: F12 → Elements.
2. Найдите действующий селектор во вкладке Styles и файл-источник.
3. Для глобального изменения проверьте переменные `base.css`, для отдельной страницы — `pages/`.
4. Измените исходник, а не только временное правило в DevTools.
5. Обновите страницу и проверьте обычное, выбранное, ошибочное и выключенное состояния.

**Практика.** Временно измените `--radius` и сравните карточки. Затем верните значение. Посмотрите, какие компоненты используют собственный радиус и почему изменение не затронуло их.

## Вопросы для защиты

**Чем padding отличается от margin?** Padding находится внутри границы элемента, margin — снаружи.

**Зачем отдельный responsive.css?** В нём собраны изменения оформления для разных размеров окна; общие стили не нужно переписывать для каждой страницы.

**Что такое каскад?** Правила выбора итогового стиля из нескольких подходящих объявлений с учётом их происхождения, важности, специфичности и порядка.
