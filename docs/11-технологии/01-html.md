# HTML: структура страниц

[Оглавление](README.md) · [Далее: CSS](02-css.md)

## Что делает HTML

HTML описывает, какие элементы находятся на странице: заголовок, абзац, ссылка, изображение, форма. Браузер читает разметку и строит дерево элементов — DOM. С этим деревом затем работает JavaScript, а CSS задаёт его оформление.

Файлы проекта: главная — [frontend/index.html](../../frontend/index.html), остальные страницы — [frontend/pages](../../frontend/pages/). Например, `booking.html` содержит шаги записи, `cart.html` — контейнер корзины, `account.html` — кабинет.

## Как устроен тег

```html
<h1 class="page-title">Барбершопы</h1>
```

`h1` — имя элемента. `<h1>` открывает его, `</h1>` закрывает, между ними находится текст. `class="page-title"` — атрибут, связывающий элемент со стилями. У элементов `img`, `input`, `meta` закрывающий тег не нужен.

```html
<a href="/pages/shop.html">Магазин</a>
<img src="/assets/img/favicon.svg" alt="Знак Blind Barber">
```

`href` задаёт адрес перехода, `src` — адрес ресурса, `alt` — текстовую замену изображения. Путь, начинающийся с `/`, отсчитывается от корня сайта, а не от папки текущего HTML-файла.

## Каркас страницы

Сокращённый учебный пример на основе [login.html](../../frontend/pages/login.html):

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Вход — Blind Barber</title>
  <link rel="stylesheet" href="/assets/css/main.css">
</head>
<body>
  <main id="main">
    <h1>С возвращением</h1>
    <form id="auth-form">
      <label for="email">Email</label>
      <input id="email" name="email" type="email" required>
      <button type="submit">Войти</button>
    </form>
  </main>
  <script type="module" src="/assets/js/pages/login.js"></script>
</body>
</html>
```

| Элемент | Зачем нужен |
|---|---|
| `<!doctype html>` | Включает стандартный режим обработки HTML |
| `html lang="ru"` | Указывает основной язык документа |
| `head` | Содержит метаданные и подключения |
| `meta charset` | Помогает правильно показывать кириллицу |
| `meta viewport` | Настраивает масштаб страницы на мобильном устройстве |
| `title` | Задаёт название вкладки браузера |
| `body` | Содержит отображаемую часть страницы |
| `main` | Обозначает основное содержимое |
| `script type="module"` | Подключает JavaScript с поддержкой `import` и `export` |

Рабочая форма проекта содержит и пароль; сокращённый пример показывает только устройство разметки.

## Семантические элементы

`header` — шапка, `nav` — навигация, `main` — основное содержимое, `section` — тематический раздел, `article` — самостоятельная карточка, `aside` — дополнительный блок, `footer` — подвал. `div` — универсальная обёртка без отдельного смыслового значения.

Для действия используйте `button`, для перехода — `a`. Семантика помогает браузерам, поисковым системам и средствам доступности понять страницу. У кнопки внутри формы задавайте `type="button"`, если она не должна отправлять форму.

Шапка и подвал Blind Barber создаются функцией `initLayout()` в [layout.js](../../frontend/assets/js/components/layout.js). Поэтому в исходном HTML они могут отсутствовать, хотя на открытой странице видны.

## Формы: id, name, label

В [booking.html](../../frontend/pages/booking.html) поле имени выглядит так:

```html
<label for="name">Имя</label>
<input class="input" id="name" name="name"
       autocomplete="name" required minlength="2">
```

`id` идентифицирует элемент на странице и должен быть уникальным. `label for="name"` связывает подпись с полем `id="name"`. `name` задаёт имя поля формы. `required` и `minlength` описывают ограничения ввода. `autocomplete` подсказывает браузеру подходящее автозаполнение.

JavaScript может прочитать это поле через `form.elements.namedItem('name').value`. В проекте форма записи проверяется JavaScript, затем данные повторно проверяет Python. Атрибуты HTML сами по себе не защищают API от неправильного запроса.

В некоторых формах есть `novalidate`: автоматическая проверка при отправке отключена, чтобы управлять сообщениями из JavaScript. В корзине она вызывается явно методом `reportValidity()`.

## Классы и data-атрибуты

```html
<button class="chip active" data-filter="all">Все</button>
```

`chip` и `active` — два класса для оформления. `data-filter="all"` хранит значение, которое JavaScript читает через `button.dataset.filter`. Это связывает кнопку фильтра с поведением в [barbershops.js](../../frontend/assets/js/pages/barbershops.js).

Не переименовывайте `id` и `data-*` только в HTML: сначала найдите их использование в JavaScript и CSS.

## Как изменить страницу

1. Откройте нужный файл в `frontend/pages/`.
2. Найдите заголовок или текст. Если его нет, проверьте соответствующий файл в `assets/js/pages/`: часть разметки создаётся из данных.
3. Измените текст, сохранив используемые `id`, классы и `data-*`.
4. Обновите браузер. При старом содержимом нажмите Ctrl+F5.
5. Проверьте страницу на телефоне или в мобильном режиме инструментов разработчика.

## Типичные ошибки

| Симптом | Что проверить |
|---|---|
| Кнопка перестала работать | Совпадают ли `id` / `data-*` с селекторами JavaScript |
| Кириллица испортилась | UTF-8 в файле и `meta charset` |
| Изображение не видно | Реальный файл и правильность `src` |
| Подпись не фокусирует поле | Совпадение `label for` и `input id` |
| При двойном щелчке по HTML нет данных | Откройте сайт через сервер на localhost:5500, а не `file://` |

## Вопросы для защиты

**Что такое DOM?** Дерево элементов, которое браузер строит по HTML и которое JavaScript может изменять.

**Почему используется один `main`?** Он обозначает основное содержимое страницы; навигация и повторяющиеся блоки находятся отдельно.

**HTML хранит записи клиентов?** Нет. HTML задаёт интерфейс; записи находятся в базе данных на сервере.

**Практика.** Измените пояснение под заголовком каталога в `barbershops.html`, обновите страницу и убедитесь, что фильтры продолжают работать.
