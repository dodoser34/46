# JavaScript: поведение сайта

[Оглавление](README.md) · [Далее: Python](04-python.md)

## Что выполняется в браузере

JavaScript обрабатывает клики, читает поля, отправляет запросы к API и обновляет DOM. В Blind Barber используется обычный JavaScript с ES-модулями: React, npm-сборка и Node.js для запуска сайта не требуются.

| Папка | Что внутри |
|---|---|
| [core](../../frontend/assets/js/core/) | API-клиент, сессия входа, корзина, форматирование, переходы |
| [components](../../frontend/assets/js/components/) | Шапка, карточки, уведомления, выбор времени, общие действия |
| [pages](../../frontend/assets/js/pages/) | Поведение каждой страницы |

У `frontend/pages/login.html` есть соответствующий `assets/js/pages/login.js`. Файл страницы соединяет разметку с общими модулями.

## Основы синтаксиса

```js
const name = 'Димаш';
let selectedTime = null;
const product = { id: 1, price: 12000 };
const items = [product];
function total(rows) {
  return rows.reduce((sum, row) => sum + row.price, 0);
}
```

`const` запрещает переназначить переменную, `let` позволяет это сделать. При этом свойства объекта, объявленного через `const`, можно менять. Строка — текст, число — числовое значение, `true` / `false` — логические значения, `null` — явное отсутствие значения. Объект хранит свойства, массив — последовательность элементов.

`map()` преобразует элементы массива, `filter()` отбирает их, `find()` ищет первый подходящий, `reduce()` накапливает результат. В каталоге `shops.map(shopRow).join('')` превращает список барбершопов в HTML карточек.

## Модули

```js
import { api } from '../core/api.js';
import { initLayout } from '../components/layout.js';
```

`export` делает функцию или объект доступным другим модулям, `import` подключает его. Относительный путь импорта отсчитывается от текущего JS-файла. В HTML модуль подключается через `script type="module"`.

Открывайте сайт через сервер. У локального `file://` нет той же модели загрузки модулей и запросов, что у HTTP-сайта.

## DOM и события

Учебный пример, соответствующий устройству формы входа:

```js
const form = document.getElementById('auth-form');
form.addEventListener('submit', async (event) => {
  event.preventDefault();
  const email = form.elements.namedItem('email').value.trim();
  console.log(email);
});
```

`getElementById` находит элемент по `id`, `querySelector` — по CSS-селектору. `addEventListener` подписывается на событие. `preventDefault()` отменяет обычную отправку формы с переходом страницы: запрос отправит JavaScript.

`textContent` удобно использовать для обычного текста. `innerHTML` создаёт разметку, поэтому пользовательские строки перед вставкой необходимо экранировать. В проекте используется функция `esc()` из [utils.js](../../frontend/assets/js/core/utils.js). Не вставляйте имя, отзыв или адрес в HTML без обработки.

## Запросы: fetch, async, await

Точка связи с сервером — [core/api.js](../../frontend/assets/js/core/api.js). Учебное сокращение вызова:

```js
try {
  const shops = await api.barbershops({ city: 'almaty' });
  console.log(shops);
} catch (error) {
  console.error(error.message);
}
```

`async` обозначает функцию, возвращающую Promise. `await` ожидает результат внутри неё; обработка других событий браузера при этом может продолжаться. `try/catch` обрабатывает отказ запроса. JSON — текстовый формат передачи структурированных данных; это не отдельная база данных.

API-клиент формирует URL, кодирует тело через `JSON.stringify`, добавляет `Content-Type`, а при входе — заголовок `Authorization: Bearer ...`. Он проверяет `response.ok`: сам `fetch()` не превращает ответ 400 или 500 в исключение автоматически.

При ошибке клиент бросает `ApiError` с `message` и `status`. Например, форма записи при ответе 409 возвращает посетителя к выбору времени, потому что слот уже заняли.

## Как работает вход

1. `login.js` читает email и пароль, проверяет заполнение.
2. `api.login()` отправляет POST `/api/auth/login`.
3. Python проверяет пароль и возвращает токен с профилем.
4. `setSession()` из [auth.js](../../frontend/assets/js/core/auth.js) сохраняет `barber_token` и `barber_user`.
5. Следующие запросы передают токен, а страница кабинета загружает профиль и историю.

Данные в `localStorage` доступны JavaScript этого сайта. Наличие сохранённого `is_admin` нужно только для отображения интерфейса: право доступа к админке сервер проверяет отдельно по токену. Просроченный токен отвергается сервером.

## Как работает корзина

В [core/cart.js](../../frontend/assets/js/core/cart.js) сохраняются только пары `{ id, qty }` под ключом `barber_cart`. Цена загружается с сервера. Количество ограничивается 20 единицами одного товара, повреждённые значения отбрасываются, повторяющиеся строки объединяются.

`pages/cart.js` загружает товары по id, показывает предварительную сумму и отправляет заказ. Перед отправкой проверяется форма; для курьера требуется адрес. Отсутствующий в каталоге товар удаляется из локальной корзины, товар без остатка нельзя заказать. Окончательную доступность и сумму всё равно проверяет сервер.

Событие `cart:change` позволяет шапке обновлять счётчик корзины без перезагрузки страницы. Это собственное событие проекта, созданное через `CustomEvent`.

## Почему ответы могут прийти не по порядку

Пользователь может быстро переключить мастера или дату. Старый запрос способен завершиться позже нового. В [slot-picker.js](../../frontend/assets/js/components/slot-picker.js) и `booking.js` используются счётчики запросов: ответ применяется, только если он относится к последнему запросу. Так прежние слоты не заменяют новый выбор.

Кнопки отправки временно выключаются, чтобы повторный клик не создавал ещё один запрос. После ошибки управление снова становится доступным, а сервер дополнительно проверяет корректность операции.

## Диагностика

| Где смотреть | Что искать |
|---|---|
| F12 → Console | Ошибки JavaScript, имя файла и строку |
| F12 → Network | URL, метод, статус, Request Payload и Response |
| F12 → Application → Local Storage | Токен, профиль и корзину своего локального сеанса |
| Окно бэкенда | Ошибки обработки запроса и базы |

Не публикуйте пароль и токен из Network или localStorage. Для демонстрации структуры запроса используйте вымышленные значения.

## Практика и вопросы

**Практика.** Откройте каталог и вкладку Network. Выберите город. Найдите GET `/api/barbershops?city=...` и сопоставьте JSON-ответ с карточками на странице.

**Чем JavaScript отличается от Java?** Это разные языки. В этом проекте используется JavaScript, Java не применяется.

**Зачем сервер, если JavaScript тоже проверяет форму?** Посетитель может изменить браузерный код или отправить запрос вручную; правила и данные должен проверять сервер.

**Зачем отделён api.js?** Заголовки, токен и обработка HTTP-ошибок реализованы один раз, а файлы страниц используют понятные методы `api.login()`, `api.createOrder()` и другие.
