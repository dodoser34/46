# 3. Функции, условия, циклы

Из этих трёх кирпичиков состоит почти любая программа.

## Функция

**Функция** — это рецепт с названием. Один раз описали, как что-то делается, и дальше
просто зовём по имени.

```python
def delivery_fee(delivery, subtotal):
    if delivery != "courier" or subtotal >= 30000:
        return 0
    return 1500
```

Разберём по словам:

| Кусок | Что значит |
|---|---|
| `def` | «Сейчас опишу функцию» (от англ. define — определить) |
| `delivery_fee` | Имя функции: «стоимость доставки» |
| `(delivery, subtotal)` | **Параметры** — что функции нужно знать: способ доставки и сумму товаров |
| `return 0` | **Вернуть** результат — ответ функции. После `return` функция заканчивается |

Как ею пользоваться (это называется **вызвать** функцию):

```python
delivery_fee("pickup", 8000)    # самовывоз → 0
delivery_fee("courier", 8000)   # курьер, сумма маленькая → 1500
delivery_fee("courier", 40000)  # курьер, сумма от 30 000 → 0, доставка бесплатно
```

Значения в скобках при вызове называются **аргументами**.

Зачем функции:

- **не повторяться**: правило доставки написано один раз, а используется везде;
- **читаемость**: `delivery_fee(...)` понятнее, чем пять строк расчёта посреди другого кода;
- **проверка**: функцию легко проверить тестом отдельно от всего остального.

Это настоящая функция из проекта: `backend/app/modules/shop/service.py`.

### Функции в JavaScript

Пишутся чуть иначе, смысл тот же:

```js
function formatPrice(value) {
  return `${Number(value).toLocaleString('ru-RU')} ₸`;
}

formatPrice(12000)   // "12 000 ₸"
```

Это функция из `frontend/assets/js/core/utils.js`: она красиво показывает цену на всех страницах.

## Условие (if / else)

**Условие** — развилка: «если так, делай одно, иначе — другое».

```python
if not slot["available"]:
    raise HTTPException(409, "Это время уже занято, выберите другое")
```

Читается по-русски: «если время **не** свободно — остановись и ответь ошибкой
"Это время уже занято"».

Полная форма:

```python
if delivery == "courier":
    print("Нужен адрес")
else:
    print("Адрес не нужен")
```

Слова, которые часто встречаются в условиях:

| Запись | Значит |
|---|---|
| `==` | равно (два знака! один `=` — это «положить в коробку») |
| `!=` | не равно |
| `>`, `<`, `>=`, `<=` | больше, меньше, больше или равно, меньше или равно |
| `and` (в JS `&&`) | и то, и другое |
| `or` (в JS `\|\|`) | хотя бы одно из двух |
| `not` (в JS `!`) | наоборот |

## Цикл (for / while)

**Цикл** — повторить одно и то же много раз.

### for — «для каждого»

```python
for item in data.items:
    print(item.product_id, item.qty)
```

«Для каждого товара в заказе — напечатай его номер и количество». Если товаров пять,
строка выполнится пять раз.

### while — «пока»

Вот как сервер строит расписание мастера на день (упрощённо, из `booking/service.py`):

```python
start = open_m                      # начинаем с открытия барбершопа (в минутах)
while start + duration <= close_m:  # пока услуга успевает закончиться до закрытия
    slots.append(start)             # добавить это время в список
    start += 60                     # сдвинуться на час
```

Если барбершоп работает с 10:00 до 22:00, а стрижка длится 60 минут, цикл добавит
10:00, 11:00, … 21:00 и остановится: в 22:00 стрижка уже не поместится.

## Ошибки как часть логики (raise / try)

Иногда программа должна **сознательно остановиться**: клиент прислал неправильные данные.
Для этого в Python есть `raise` — «поднять ошибку»:

```python
if day < today:
    raise HTTPException(400, "Запись доступна на ближайшие 30 дней")
```

Сервер прекращает обработку и отправляет сайту это сообщение. Сайт показывает его человеку.

А `try / except` — «попробуй, а если не вышло — сделай вот это»:

```python
try:
    db.commit()            # попробовать сохранить запись в базу
except IntegrityError:     # база отказалась: время только что занял кто-то другой
    db.rollback()          # отменить
    raise HTTPException(409, "Это время уже занято, выберите другое")
```

В JavaScript то же самое: `throw` и `try { … } catch { … }`.
