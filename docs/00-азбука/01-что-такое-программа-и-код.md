# 1. Что такое программа и код

Этот раздел для тех, кто никогда не программировал. Если вы уже знаете, что такое переменная
и функция, можно сразу переходить к [рассказу о проекте](../../ПРОЕКТ-ПРОСТЫМИ-СЛОВАМИ.md).

## Программа

**Программа** — это список указаний для компьютера. Компьютер сам ничего не умеет и ни о чём
не догадывается. Он делает ровно то, что написано, строчку за строчкой.

Похоже на рецепт:

```
1. Налить воду в чайник.
2. Включить чайник.
3. Если вода закипела — выключить.
```

Повар-человек поймёт и рецепт с ошибкой. Компьютер — нет: если в рецепте опечатка, он остановится
и скажет «не понимаю».

## Код

**Код** — это текст программы. Обычный текст в файле, который можно открыть в Блокноте.
Пишут его на специальном **языке программирования**, потому что обычный русский язык для
компьютера слишком расплывчатый.

У нас в проекте четыре таких языка:

| Язык | Для чего | Где лежит |
|---|---|---|
| **HTML** | Что есть на странице: заголовок, кнопка, картинка | файлы `.html` в папке `frontend` |
| **CSS** | Как это выглядит: цвета, шрифты, отступы | файлы `.css` |
| **JavaScript** | Что происходит при нажатии, как страница берёт данные с сервера | файлы `.js` |
| **Python** | Сервер: хранит данные, проверяет записи и заказы | файлы `.py` в папке `backend` |

Строго говоря, HTML и CSS — не языки программирования, а языки **разметки** и **оформления**:
в них нет команд «если… то…». Они просто описывают страницу. А JavaScript и Python — настоящие
языки программирования.

## Файл и папка

**Файл** — один документ на диске: `main.py`, `index.html`, `logo.svg`.
Последняя часть после точки называется **расширением** и подсказывает, что внутри:
`.py` — код на Python, `.js` — JavaScript, `.jpg` — фотография, `.md` — текст вроде этого.

**Папка** — коробка для файлов. Проект — это одна большая папка, внутри которой разложены
файлы по смыслу: сайт отдельно (`frontend`), сервер отдельно (`backend`), документация отдельно (`docs`).

## Комментарий

**Комментарий** — строчка в коде, которую компьютер пропускает. Она пишется для людей:
объяснить, зачем здесь это сделано.

```python
SLOT_STEP = 60          # шаг сетки времени, минут
```

Всё, что после `#` в Python (и после `//` в JavaScript), — комментарий. В проекте комментарии
на русском, чтобы их было легко читать.

## Синтаксис и ошибки

**Синтаксис** — правила записи языка: где ставить скобки, двоеточия, кавычки.
Как правила орфографии, только строже.

**Ошибка (баг)** — место, где программа работает не так, как задумано. Бывают два вида:

- компьютер не понял текст (забыли скобку) — программа даже не запустится;
- компьютер понял, но сделал не то (например, разрешил записаться на занятое время) —
  это хуже, потому что видно не сразу. Для поиска таких ошибок пишут **тесты** (см. главу 4).

## Запуск

Чтобы программа заработала, её надо **запустить**. Код на Python запускает программа-переводчик,
которая тоже называется `python`. Она читает файлы `.py` и выполняет их.

Код на JavaScript запускает **браузер** (Chrome, Edge), когда открывает страницу сайта.

В нашем проекте всё запускается одним файлом `START.cmd` — подробно в [ЗАПУСК.md](../../ЗАПУСК.md).
