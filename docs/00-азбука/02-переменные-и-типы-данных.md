# 2. Переменные и типы данных

## Переменная

**Переменная** — это коробка с наклейкой. На наклейке написано имя, внутри лежит значение.

```python
price = 12000
```

Это значит: «возьми коробку с наклейкой `price` и положи в неё число 12000».
Знак `=` здесь означает не «равно», а **«положить в коробку»**. Это называется **присваивание**.

Потом можно достать значение по имени:

```python
price = 12000
total = price + 1500     # в total окажется 13500
```

Компьютер видит слово `price`, заглядывает в коробку, берёт оттуда 12000 и прибавляет 1500.

Зачем это нужно? Чтобы не писать одно и то же число в двадцати местах. Если цена изменится,
меняем её в одной коробке, а не по всему коду.

### Почему «переменная»

Потому что содержимое можно поменять:

```python
total = 0          # сначала в корзине ноль
total = total + 5000   # положили товар — стало 5000
total = total + 3000   # ещё товар — стало 8000
```

Ровно так в проекте считается сумма заказа (файл `backend/app/modules/shop/service.py`):

```python
total = 0
for product_id, qty in ...:
    ...
    total += product.price * qty   # += значит «прибавь к тому, что уже лежит»
```

### Константа

**Константа** — переменная, которую договорились не менять. В Python их пишут БОЛЬШИМИ буквами.
В проекте это настройки, которые легко найти и поправить:

```python
DELIVERY_FEE = 1500          # курьерская доставка по городу, ₸
FREE_DELIVERY_FROM = 30000   # бесплатная доставка от суммы, ₸
SLOT_STEP = 60               # шаг сетки времени, минут
BOOKING_HORIZON = 30         # на сколько дней вперёд можно записаться
```

Хотите доставку за 2000 ₸ — меняете одно число, и весь сайт сразу считает по-новому.

### Переменные в JavaScript

В JavaScript то же самое, только перед именем пишут слово:

```js
const API_BASE = '/api';     // const — коробку нельзя перезаписать
let step = 1;                // let — можно перезаписать
step = 2;
```

## Типы данных

В коробку можно положить разные вещи. Вид вещи называется **тип данных**.

| Тип | Что это | Пример из проекта |
|---|---|---|
| **Целое число** (`int`) | Количество, цена, номер | `price = 12000`, `duration = 60` |
| **Дробное число** (`float`) | Число с запятой (пишется через точку) | `rating = 4.9` |
| **Строка** (`str`, string) | Любой текст, всегда в кавычках | `name = "The Cut"`, `time = "13:00"` |
| **Логическое** (`bool`, boolean) | Только «да» или «нет»: `True` / `False` | `is_admin = False`, `available = True` |
| **Пусто** (`None` в Python, `null` в JS) | «Здесь ничего нет» | у гостя без аккаунта `user_id = None` |
| **Список** (`list`, в JS — массив) | Несколько значений по порядку | `["Алматы", "Астана", "Костанай"]` |
| **Словарь** (`dict`, в JS — объект) | Пары «название → значение» | `{"time": "13:00", "available": True}` |

### Почему важно не путать типы

`"60"` в кавычках — это **текст** из двух символов, а `60` без кавычек — **число**.

```python
60 + 60       # 120
"60" + "60"   # "6060" — строки просто склеились
```

Поэтому сервер проверяет, что ему прислали именно число там, где ждёт число.
Этим занимается библиотека Pydantic (см. [словарь](../10-словарь/словарь-терминов.md)).

### Список

**Список** — несколько значений в одной коробке, по порядку. Каждое значение имеет номер,
и считать начинают **с нуля**:

```python
cities = ["Алматы", "Астана", "Костанай"]
cities[0]   # "Алматы"
cities[2]   # "Костанай"
len(cities) # 3 — сколько всего
```

В проекте списками хранятся, например, товары в корзине и свободное время мастера на день.

### Словарь (объект)

**Словарь** — как анкета: слева название поля, справа значение.

```python
slot = {"time": "13:00", "available": True}
slot["time"]        # "13:00"
slot["available"]   # True
```

В JavaScript то же самое называется **объект**:

```js
const item = { id: 3, qty: 2 };   // товар №3, две штуки — так лежит товар в корзине
item.qty   // 2
```

Почти все данные, которые сайт и сервер передают друг другу, — это словари и списки,
записанные в формате **JSON** (подробнее в [главе 5](05-как-работает-сайт.md)).
