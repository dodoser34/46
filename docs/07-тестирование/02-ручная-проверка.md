# Ручная проверка — чек-лист

Пройдите по списку перед защитой. Отмечайте `[x]`, когда пункт проверен.

## Общее
- [ ] После START.cmd сайт открывается по `http://localhost:5500`, в шапке логотип Blind Barber (Docker: порт 8000)
- [ ] Меню работает, на телефоне открывается «бургер»
- [ ] Шапка прячется при прокрутке вниз и появляется при прокрутке вверх
- [ ] Переход между страницами плавный
- [ ] Несуществующий адрес (`/abc`) показывает страницу 404

## Главная
- [ ] Заголовок выезжает по строкам, фото барбера появляется
- [ ] Поиск по городу и услуге ведёт в каталог с фильтрами
- [ ] Цифры «отсчитываются», бегущая строка двигается
- [ ] Подписка на новости показывает «Вы подписаны»

## Барбершопы
- [ ] Фильтр по городу и поиск работают
- [ ] «Рядом со мной» спрашивает разрешение и показывает расстояние в км
- [ ] «Открыто сейчас» скрывает закрытые
- [ ] Сердечко без входа предлагает войти, после входа — добавляет в избранное

## Страница барбершопа и мастера
- [ ] Все 5 вкладок открываются, фото в галерее открываются на весь экран
- [ ] Быстрая запись: занятые часы зачёркнуты
- [ ] Страница мастера: работы, отзывы, кнопка «Записаться к мастеру»

## Запись
- [ ] 4 шага проходятся, справа обновляется сводка и цена
- [ ] Неверный телефон подсвечивается красным
- [ ] После записи — «Вы записаны!» и номер
- [ ] На то же время у того же мастера записаться уже нельзя

## Магазин
- [ ] Категории, поиск и сортировка работают
- [ ] Товар «летит» в корзину, счётчик в шапке растёт
- [ ] В корзине меняется количество, удаляется товар
- [ ] Курьер < 30 000 ₸ — доставка 1 500 ₸; ≥ 30 000 ₸ — бесплатно
- [ ] Заказ оформляется, корзина очищается

## Аккаунт
- [ ] Регистрация нового пользователя
- [ ] В кабинете видны записи, заказы, избранное; запись можно отменить
- [ ] Изменение имени и телефона сохраняется
- [ ] Выход работает

## Администратор (`admin@barber.kz` / `admin123`)
- [ ] Сводка показывает цифры
- [ ] Фильтры записей по дате и статусу
- [ ] Смена статуса записи и заказа
- [ ] Отмена заказа возвращает товары на склад один раз; восстановление повторно резервирует их
- [ ] Выполненные заказы отражаются в итоговой сумме сводки, новые — не включаются
- [ ] Нельзя восстановить запись поверх другого приёма с пересекающимся временем

## Телефон
- [ ] В браузере `F12` → значок телефона (режим устройства) → iPhone / Galaxy: ничего не вылезает за край
- [ ] Все формы удобно заполнять, кнопки крупные
