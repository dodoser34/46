# Автоматические тесты

**Автотест** — это маленькая программа, которая сама проверяет, что другая программа работает правильно.
Как контрольный покупатель: заходит, делает заказ и сверяет результат с ожидаемым.

Файлы: `backend/tests/conftest.py` (подготовка), `test_api.py` (основные API), `test_frontend_server.py` (статика и прокси), `test_dev_launch.py` (настоящие команды запуска), `test_workflows.py` (склад, статусы, параллельные операции и проверки данных).
Используется библиотека **pytest**.

## Как запустить

```bash
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

Перед первым запуском установите зависимости тестирования через `backend/setup.cmd`.
Ожидается завершение без ошибок: строка `passed` в конце. Точный результат зафиксирован в [отчёте о проверке](03-готовность-проекта.md).

Тесты работают с **отдельной временной базой**, поэтому не портят ваши данные.

## Фронтенд и команды запуска

`test_frontend_server.py` проверяет передачу тела, авторизации, параметров и ошибочного статуса через прокси, работу статики без API, сообщение об отключённом бэкенде, MIME JavaScript, HEAD и страницу 404.

`test_dev_launch.py` действительно запускает `.cmd` из корня и из папок frontend/backend, проверяет HTML, API, вход и авторизацию. Отдельный сценарий меняет время модификации Python-файла и проверяет, что API перезапустился, токен сохранился, а фронтенд продолжает работать; метаданные файла затем восстанавливаются. Используются отдельная SQLite-база и свободные порты. Эти три теста предназначены для Windows и пропускаются на других ОС.

## Полные сценарии и регрессии

`test_workflows.py` проверяет:

- возврат остатков при отмене ровно один раз и резервирование при восстановлении;
- отказ в восстановлении, если товара больше нет;
- сумму только выполненных заказов в сводке;
- откат всего списания при ошибке одной позиции;
- общий лимит количества при повторении товара в запросе;
- одновременную покупку последнего товара;
- пересечение записей с разным началом и восстановление отменённой записи;
- отказ для имён и отзывов, состоящих только из пробелов;
- HTML-страницу 404 для сайта и JSON-ошибку 404 для API.

API-тесты не заменяют проверку взаимодействия в браузере. Команды и проверенные пользовательские пути перечислены в [отчёте](03-готовность-проекта.md).
