# Готовность проекта и результаты проверки

Проект полностью готов к запуску на компьютере и к показу на защите. Ниже — что именно проверено.

## Автоматические проверки

Команда из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

Результат: **62 теста, все проходят** (62 passed). На Linux три теста запуска через `.cmd`
пропускаются, потому что такие файлы бывают только в Windows.

Иногда pytest пишет одно предупреждение (warning) про устаревшее имя внутри библиотеки Starlette.
Это не ошибка нашего кода и на работу тестов не влияет.

| Набор | Что проверяет |
|---|---|
| `test_api.py` | Регистрация и вход, каталог, отзывы, записи, заказы, админка, служебные команды |
| `test_workflows.py` | Остатки товаров, отмена и восстановление, выручка выполненных заказов, одновременные запросы, проверка форм, страницы 404 |
| `test_frontend_server.py` | Сервер сайта: раздача файлов, пересылка запросов `/api` на сервер Python, сообщения, если сервер выключен |
| `test_dev_launch.py` | Запуск через `START.cmd` и по отдельности из папок `frontend` / `backend`, автоперезапуск API после правки кода |
| `test_pages_build.py`, `test_pages_export.py` | Сборка демо-версии для GitHub Pages; в неё не попадают пароли и настройки сервера |

Что гарантируют тесты:

- на одно время к одному мастеру нельзя записать двух человек, даже если запросы пришли одновременно;
- два покупателя не могут купить одну последнюю единицу товара;
- если одна позиция заказа не прошла, не сохраняется ни одна;
- одного товара нельзя заказать больше 20 штук, даже если разбить его на несколько строк;
- отмена заказа возвращает товар на склад один раз, восстановление снова его резервирует
  (и не даёт восстановить, если товара уже нет);
- выручка в админке считает только выполненные заказы вместе с доставкой;
- имя или отзыв из одних пробелов не принимаются;
- неизвестная страница показывает оформленную страницу 404, а неизвестный адрес API — ответ в формате JSON.

## Проверка в браузере

Сайт проверен в браузере Edge на компьютере (1440×1000) и на ширине телефона (390×844).

| Что делали | Результат |
|---|---|
| Открыли главную, услуги, барбершопы, барбершоп, мастера, магазин, товар, «О нас», корзину | Страницы и данные загружаются |
| Регистрация → личный кабинет | Пользователь создан, профиль показан |
| Добавить в избранное → кабинет | Барбершоп сохранён и отображается |
| Услуга на 90 минут → мастер → дата и время → подтверждение | Запись создана |
| Кабинет → отменить запись | Статус сохранён, кнопка отмены пропала |
| Товар → корзина → доставка курьером → заказ | Без адреса не оформляется; заказ создан и виден в истории |
| Администратор: отменить → восстановить → выполнить заказ | Статусы сохраняются |
| Испорченные данные корзины в браузере | Корзина сама исправилась, лишний товар убран |
| Несуществующая страница / несуществующий адрес API | Страница 404 в стиле сайта / JSON с кодом 404 |
| Главная на телефоне | Всё помещается, горизонтальной прокрутки нет |

Ошибок JavaScript в консоли браузера нет. Все изображения, на которые ссылается сервер, существуют.

Геолокацию («Рядом со мной») и разные системные настройки анимации удобнее проверить руками —
для этого есть [чек-лист ручной проверки](02-ручная-проверка.md).

## Перенос на другой компьютер

Проверено, что проект, скачанный через Git на чистый компьютер, запускается одним `START.cmd`:
он сам создаёт окружение `.venv`, ставит библиотеки, копирует пример настроек `.env` и создаёт
демо-базу. Созданные при запуске файлы в Git не попадают.
Подробно — [ЗАПУСК.md](../../ЗАПУСК.md) и [что передаётся через Git](../02-запуск/04-что-передаётся-через-git.md).

## Демо для GitHub Pages

Workflow `.github/workflows/pages.yml` сам прогоняет тесты, собирает статическую версию сайта
и публикует её. Демо проверено локально: страницы, фильтр города, регистрация, вход, избранное,
запись и её отмена, заказ с курьером, действия администратора, выход и кнопка «Сбросить демо».

В демо изменения хранятся только в браузере текущего посетителя. Полная версия с сервером
и базой запускается через `START.cmd`. [Инструкция по публикации](../08-деплой/04-github-pages.md).

## Что не входит в проект

Оплата — при получении. Онлайн-оплата картой, отправка SMS и email, реальная служба доставки
не подключались: для них нужны договоры с банком и сервисами. Подписка на новости сохраняет email в базе.

Настройки Docker и PostgreSQL подготовлены. Перед размещением в интернете используйте
[инструкцию по деплою](../08-деплой/02-инструкция-по-деплою.md), задайте свой пароль администратора,
домен и HTTPS.
