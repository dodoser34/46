# Готовность проекта и результаты проверки

Дата обновления проверки: **18 октября 2026 года**.

Проект проверен для локального запуска и демонстрации основных функций. Автотесты и браузерная проверка выполнены на отдельных базах: рабочие записи и заказы пользователя не менялись.

## Что исправлено при завершении

- Заказы резервируют остаток условным UPDATE: два покупателя не могут купить одну последнюю единицу товара.
- Ошибка одной позиции откатывает изменения всех позиций заказа.
- Повторяющиеся позиции объединяются с общим ограничением 20 единиц одного товара.
- Отмена заказа возвращает товар один раз. Восстановление заново резервирует остатки и отклоняется, если их недостаточно.
- Итоговая сумма в админке учитывает выполненные заказы, включая доставку; новые и отменённые туда не входят.
- Пересекающиеся записи защищены при одновременных запросах и восстановлении отменённого приёма.
- После ошибки смены статуса админка заново загружает данные, чтобы не показывать несохранённое значение.
- Корзина восстанавливается после некорректных данных localStorage; отсутствующие товары удаляются, товары без остатка блокируют оформление.
- Формы проверяют обязательные поля, адрес курьера и имена; имя или отзыв из одних пробелов отвергаются сервером.
- Страница 404 использует оформление проекта; неизвестный API возвращает JSON, а не HTML.
- При системном уменьшении движения значок успешной записи показывается сразу, без ожидания прорисовки.
- На Windows изменение Python-файла перезапускает только API. Фронтенд и общий запуск сохраняются; штатный механизм рассылки Ctrl+C из reloader Uvicorn не используется.
- Точки запуска размещены в `frontend/start.cmd`, `backend/start.cmd`, `backend/setup.cmd`; общий `START.cmd` находится в корне.

## Автоматические проверки

Команда из корня проекта:

```powershell
backend\.venv\Scripts\python.exe -m pytest backend/tests -q -p no:cacheprovider
```

Базовая версия прошла 44 теста; после добавления GitHub Pages набор расширен тестами сборки и экспорта данных. Итоговый результат приведён в разделе GitHub Pages ниже. Есть одно предупреждение об устаревшем псевдониме AnyIO внутри установленного Starlette TestClient; выполнение тестов оно не нарушает.

Дополнительно проверены синтаксис 28 модулей JavaScript и 37 Python-файлов, локальные ссылки в 43 Markdown-документах и пути ресурсов HTML. Ошибок в этих проверках нет.

Все 57 путей изображений, возвращённых API для услуг, товаров, барбершопов и мастеров, указывают на существующие файлы.

- 11 контрольных путей личных / служебных файлов исключаются, 14 контрольных обязательных файлов остаются доступными.
- Из разрешённых правилами файлов создан временный Git-репозиторий, а затем настоящий локальный клон из 280 исходных файлов. Рабочая папка автора при этом не инициализировалась как репозиторий.
- В клоне изначально отсутствовали `.venv`, `.env` и база.
- Его `START.cmd` самостоятельно создал новое окружение, установил зависимости, скопировал пример настроек и создал демо-базу.

## Проверка интерфейса

Среда: **Windows, Edge через Playwright**. Browser plugin отсутствовал, использован доступный Playwright. Проверочные серверы: сайт `http://localhost:15500`, API `http://localhost:18000`, отдельная SQLite-база. Стандартные адреса пользовательского запуска — 5500 и 8000.

Размеры: настольный **1440×1000**, мобильный **390×844**. Проверены содержимое и заголовки страниц, отсутствие пустой оболочки и аварийного оверлея, реальные действия, ответы API и скриншоты. Ошибок выполнения JavaScript и неожиданных HTTP-ошибок не обнаружено.

Подготовлен workflow `.github/workflows/pages.yml` для репозитория `dodoser34/50`. Сборка учитывает префикс `/50/`, исключает серверные файлы из сайта и экспортирует только свежие демо-данные. Финальный локальный прогон: **62 passed**, ошибок нет. Проверены ссылки 44 Markdown-файлов и синтаксис 29 JavaScript-модулей / 39 Python-файлов. На Linux три теста Windows-команд `.cmd` пропускаются по платформе.

Без FastAPI пройдены основные страницы, фильтр города, регистрация вымышленного посетителя, вход, избранное, запись на 90 минут и отмена, заказ с курьером и история, отмена / восстановление / выполнение заказа администратором, выход и сброс демо. Коммит и push выполняет владелец. Публичная публикация считается завершённой после зелёного задания deploy в GitHub Actions и проверки адреса https://dodoser34.github.io/50/; локальные проверки не выдаются за факт публикации.
