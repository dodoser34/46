# Как пользоваться этой документацией

## Если вы никогда не программировали

1. Прочитайте [азбуку](../00-азбука/01-что-такое-программа-и-код.md) — 5 коротких глав: программа, переменная,
   функция, условие, цикл, класс, сервер, база данных. Примеры взяты прямо из кода проекта.
2. Затем — [весь проект простыми словами](../../ПРОЕКТ-ПРОСТЫМИ-СЛОВАМИ.md). Там есть готовый рассказ на 2 минуты.

## Если времени мало

1. Прочитайте [весь проект простыми словами](../../ПРОЕКТ-ПРОСТЫМИ-СЛОВАМИ.md) или [01-что-это-за-проект.md](01-что-это-за-проект.md) — 5 минут.
2. Запустите сайт по инструкции [02-запуск/01-запуск-на-компьютере.md](../02-запуск/01-запуск-на-компьютере.md).
3. Перед защитой выучите [09-защита-диплома/01-план-выступления.md](../09-защита-диплома/01-план-выступления.md)
   и пролистайте [вопросы и ответы](../09-защита-диплома/02-вопросы-и-ответы.md).

## Если хотите понять всё

Читайте папки по номерам: от общей картины ([03-устройство](../03-устройство/)) к деталям
([04-сайт-фронтенд](../04-сайт-фронтенд/), [05-сервер-бэкенд](../05-сервер-бэкенд/), [06-база-данных](../06-база-данных/)).

## Обозначения

- `вот так` — названия файлов, папок, команд и адресов. Их можно копировать как есть.
- **Жирным** — главное в абзаце.
- > Цитата — совет или важное предупреждение.
- Схемы нарисованы в формате Mermaid: на GitHub и в VS Code (с расширением «Markdown Preview Mermaid Support»)
  они показываются картинками. Если видите текст вида `flowchart LR` — это та же схема в текстовом виде.

## Как открыть эти файлы

Файлы с окончанием `.md` — это обычный текст с простой разметкой (Markdown).

- **VS Code** — откройте файл и нажмите `Ctrl + Shift + V`, чтобы увидеть красиво оформленную версию.
- **GitHub** — если проект загружен туда, файлы показываются оформленными сразу.
- **Блокнот** — тоже откроет, только без оформления.
