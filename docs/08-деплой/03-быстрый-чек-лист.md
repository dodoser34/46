# Быстрый деплой — чек-лист на одну страницу

Всё в проекте уже подготовлено. Осталось пройти по шагам.

## Перед деплоем (один раз)

- [ ] Тесты проходят: `powershell -ExecutionPolicy Bypass -File scripts/test.ps1` → строка `passed` без ошибок
- [ ] Все фото на месте в `frontend/assets/img/` (тёмных плашек BLIND BARBER на сайте нет)
- [ ] Проект загружен на GitHub (см. «Подготовка» в [инструкции](02-инструкция-по-деплою.md#подготовка-для-вариантов-a-и-b-через-git))

## Render — 5 кликов

- [ ] render.com → войти через GitHub
- [ ] New → **Blueprint** → выбрать репозиторий
- [ ] Apply → дождаться зелёного статуса **Live**
- [ ] Открыть адрес сайта, проверить `/api/health`
- [ ] Environment → скопировать `ADMIN_PASSWORD`, войти в админку

## VPS — 3 команды

- [ ] `ssh root@IP`
- [ ] `git clone https://github.com/ЛОГИН/blind-barber.git && cd blind-barber`
- [ ] `sudo bash deploy/vps/install.sh ДОМЕН ПОЧТА` (или без аргументов — по IP)
- [ ] Сохранить пароль администратора из вывода скрипта

## После деплоя

- [ ] Сайт открывается, есть замочек HTTPS (на Render — сразу, на VPS — если указан домен)
- [ ] Записаться на стрижку → запись видна в админке
- [ ] Оформить заказ → заказ виден в админке
- [ ] Открыть сайт с телефона
- [ ] (по желанию) сменить email/пароль администратора: команда `set-password` или `create-admin`

## Что уже сделано в проекте для деплоя

| Готово | Где |
|---|---|
| Docker-образ с проверкой здоровья, отдельным пользователем и подготовкой базы перед запуском | `Dockerfile` |
| Render: сайт + PostgreSQL + автогенерация пароля + автодеплой из GitHub | `render.yaml` |
| Docker Compose: простой (SQLite) и продакшен (PostgreSQL) | `docker-compose.yml`, `docker-compose.postgres.yml` |
| Установка на VPS одной командой: nginx, автозапуск, HTTPS, резервные копии | `deploy/vps/install.sh` |
| Обновление и резервные копии на VPS | `deploy/vps/update.sh`, `deploy/vps/backup.sh` |
| Поддержка PostgreSQL (драйвер psycopg, авто-исправление адреса базы) | `backend/requirements.txt`, `core/config.py` |
| Защита: лимит попыток входа, срок жизни входа, заголовки безопасности, запрет пароля admin123 в production | `core/`, `main.py` |
| Защита от двойной записи на уровне базы | `models/booking.py` |
| Сжатие ответов (быстрее загрузка) | `main.py` |
| Проверка здоровья с проверкой базы | `/api/health` |
| Служебные команды: init-db, create-admin, set-password, backup, check | `backend/app/manage.py` |
| Примеры настроек для компьютера и для сервера | `backend/.env.example`, `deploy/.env.production.example` |
