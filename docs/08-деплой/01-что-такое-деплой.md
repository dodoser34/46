# Что такое деплой

**Деплой** (от англ. deploy — «развернуть») — это размещение сайта на сервере в интернете,
чтобы его могли открыть все, а не только вы на своём компьютере.

Сейчас сайт работает **только локально** (`localhost`). Сервера пока нет — когда он появится,
всё готово для размещения. Подробная инструкция: [02-инструкция-по-деплою.md](02-инструкция-по-деплою.md), коротко — [03-быстрый-чек-лист.md](03-быстрый-чек-лист.md).

## Три варианта, которые подготовлены

| Вариант | Сложность | Цена | Для чего |
|---|---|---|---|
| **Render.com** (сайт + PostgreSQL) | Легко: несколько кликов | Бесплатно | Показать сайт по ссылке на защите |
| **Docker** на любом сервере | Средне | Зависит от сервера | Надёжный запуск «как у себя» |
| **VPS** (свой сервер Ubuntu) | Одна команда `install.sh` | от ~2 000 ₸/мес | Постоянная работа с доменом и HTTPS |

## Подготовленные файлы

| Файл | Что это простыми словами |
|---|---|
| `Dockerfile` | «Рецепт» коробки: взять Python, положить сайт, установить библиотеки, запустить |
| `docker-compose.yml` | Запуск этой коробки одной командой, база хранится отдельно и не теряется |
| `.dockerignore` | Что не класть в коробку (лишние файлы, базу, настройки) |
| `render.yaml` | Настройки для хостинга Render: он сам соберёт коробку из Dockerfile |
| `deploy/nginx/barber.conf` | Настройки веб-сервера nginx, который стоит «перед» сайтом на VPS и раздаёт картинки быстрее |
| `deploy/systemd/barber.service` | Автозапуск сайта на сервере Linux (и перезапуск, если упал) |
| `backend/.env.example` | Пример настроек: пароль админа, где хранить базу |
| `/api/health` | Адрес «я жив» — хостинг по нему проверяет, что сайт работает |

## Что важно сделать при размещении

1. Задать свой пароль администратора (`ADMIN_PASSWORD`).
2. Включить HTTPS (замочек в адресной строке) — на Render включён сам, на VPS — командой `certbot`.
3. Проверить, что база хранится на постоянном диске (на бесплатном Render она сбрасывается при перезапуске).
