# Демо-данные (наполнение базы)

Файлы: `backend/app/seed/data.py` (сами данные) и `backend/app/seed/seed.py` (запись в базу).

При **первом** запуске сервер видит пустую базу и заполняет её. Если в базе уже есть данные —
ничего не трогает. Отключить наполнение: `SEED_DEMO_DATA=false` в `backend/.env`.

## Как поменять данные под реальный бизнес

1. Отредактировать `backend/app/seed/data.py` (названия, адреса, цены, мастеров).
2. Остановить сервер, удалить `backend/data/barber.db`, запустить сервер — база создастся заново.
3. Положить реальные фото по тем же путям в `frontend/assets/img/`.
