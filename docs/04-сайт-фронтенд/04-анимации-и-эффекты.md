# Анимации и эффекты

Все анимации собраны в двух файлах:
- `assets/js/components/motion.js` — **логика** (когда и что запускать);
- `assets/css/motion.css` — **внешний вид** анимаций.

## Список эффектов

| Эффект | Где | Как сделано (простыми словами) |
|---|---|---|
| Заставка главной | Главная | Строки заголовка по очереди выезжают снизу, фон «отдаляется», мужчина выплывает из размытия |
| Параллакс | Главная, магазин, «О нас», вход | Картинка разрезана на слои (фон, надпись, фигура). Каждый слой сдвигается за мышью с разной силой — возникает глубина |
| Появление при прокрутке | Везде | Браузер сообщает, когда блок попал на экран (технология IntersectionObserver), и блок плавно выплывает снизу. Соседние блоки — с задержкой друг за другом |
| Слова заголовков | Все заголовки разделов | Скрипт делит заголовок на слова, и они выезжают по одному |
| Счётчики | Цифры на главной, «О нас», админка | Число растёт от 0 до нужного значения за 1,4 секунды |
| Наклон карточек | Карточки барбершопов, услуг, мастеров, товаров | Карточка поворачивается в 3D за курсором, по ней пробегает медный блик |
| Магнитные кнопки | Медные кнопки | Кнопка слегка «тянется» к курсору |
| Курсор-кольцо | Весь сайт (только мышь) | За курсором плавно следует кольцо; на фото становится медным кругом с надписью «Открыть» |
| Волна при нажатии | Кнопки, дни, время | От места нажатия расходится круг |
| Прогресс прокрутки | Верх экрана | Тонкая медная полоса показывает, сколько страницы прочитано |
| Прячущаяся шапка | Весь сайт | Листаете вниз — шапка уезжает, вверх — возвращается |
| Моргающий логотип | Шапка | Ресницы-зубья закрытого глаза «моргают» при загрузке и наведении |
| Полёт в корзину | Магазин, товар | Кружок с фото товара летит дугой в иконку корзины, корзина подпрыгивает |
| Искры | Избранное, успешная запись, заказ | Из точки разлетаются медные искры ✦ |
| Галочка | Экран «Вы записаны!» | Галочка «рисуется», вокруг расходится кольцо |
| Переход между страницами | Весь сайт | Страница плавно закрывается тёмной «шторкой» с логотипом, новая открывается и выплывает снизу |
| Живой фон | Весь сайт | Медленно плавающие пятна света и зерно |

## Плавный переход между страницами

Сделан «шторкой» и работает **одинаково во всех браузерах**:

1. При нажатии на ссылку сайта страница за 0,4 секунды плавно закрывается тёмным экраном с логотипом.
2. Браузер переходит на новую страницу. Маленький скрипт в самом начале новой страницы ещё **до отрисовки**
   включает шторку — поэтому не видно «мигания» белым или недогруженной страницы.
3. Когда страница готова (загрузились шрифты), шторка растворяется, а содержимое мягко выплывает снизу.

Где в коде: `assets/js/core/nav.js` (уход со страницы), `components/motion.js` (обработка ссылок и прихода),
`assets/css/motion.css` (сама шторка). Если скрипт по какой-то причине не сработает, шторка всё равно
исчезнет сама через 2 секунды — страница никогда не «застрянет» закрытой.

## Забота о производительности и людях

- Анимации используют только «лёгкие» свойства (прозрачность и сдвиг), которые видеокарта
  рисует без нагрузки на процессор, поэтому не тормозят даже на телефонах.
- Эффекты, нужные только мыши, на сенсорных экранах **не включаются**.
- Если в настройках системы включено **«уменьшить движение»**, все анимации отключаются
  и контент просто сразу виден — это требование доступности.
- Если JavaScript не загрузился, контент всё равно виден: блоки скрываются **только** скриптом
  в момент запуска анимаций.
