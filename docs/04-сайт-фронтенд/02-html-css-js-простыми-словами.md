# HTML, CSS и JavaScript простыми словами

Подробный разбор каждого языка и Python с примерами исходников — в [новом руководстве](../11-технологии/README.md).

Любая страница в интернете — это три вещи вместе. Сравним с человеком:

| Язык | Роль | Аналогия | Пример из проекта |
|---|---|---|---|
| **HTML** | Что есть на странице | Скелет | «здесь заголовок, здесь кнопка, здесь фото» |
| **CSS** | Как это выглядит | Внешность и одежда | «кнопка медного цвета, скруглённая, текст жирный» |
| **JavaScript** | Как это себя ведёт | Мышцы и нервы | «при нажатии на кнопку отправь запись на сервер» |

## HTML — пример

```html
<h1 class="page-title">Барбершопы</h1>
<button class="chip active">Все</button>
```

`<h1>` — заголовок первого уровня, `<button>` — кнопка. `class="..."` — «ярлык»,
по которому CSS понимает, как это оформить.

## CSS — пример

```css
.chip.active {
  background: var(--accent);   /* медный фон */
  color: #17110b;              /* тёмный текст */
  font-weight: 600;            /* полужирный */
}
```

`var(--accent)` — это **переменная**: медный цвет задан один раз в `base.css`,
и если его поменять — он поменяется на всём сайте.

## JavaScript — пример

```js
const shops = await api.barbershops({ city: 'almaty' });   // спросить у сервера
listEl.innerHTML = shops.map(shopRow).join('');             // нарисовать карточки
```

## Почему без фреймворков (React, Vue)

Проект сделан на **чистом** HTML, CSS и JavaScript — без React и сборщиков. Причины:

- **проще понять и защитить**: каждый файл можно открыть и прочитать, нет «магии»;
- **не нужно ничего собирать** перед запуском — браузер читает файлы как есть;
- **быстро грузится**: нет тяжёлых библиотек;

## Модули — как JavaScript разложен по файлам

Скрипты подключаются как **модули** (`type="module"`): каждый файл отвечает за своё
и «импортирует» нужное из других:

```js
import { api } from '../core/api.js';           // связь с сервером
import { initLayout } from '../components/layout.js';  // шапка и подвал
```

| Папка | Что внутри | Пример |
|---|---|---|
| `js/core/` | Основа, без которой ничего не работает | `api.js` — все запросы к серверу в одном месте; `auth.js` — вход/выход; `cart.js` — корзина; `utils.js` — форматирование цен и дат |
| `js/components/` | Детали, которые повторяются на разных страницах | `cards.js` — карточки; `slot-picker.js` — выбор даты и времени; `motion.js` — анимации; `logo.js` — логотип |
| `js/pages/` | По одному скрипту на страницу | `booking.js` — мастер записи |

## Где браузер хранит данные

| Что | Где | Зачем |
|---|---|---|
| Корзина | `localStorage` браузера | Не пропадает при перезагрузке, сервер не нужен до оформления |
| Токен входа | `localStorage` браузера | Чтобы не входить заново на каждой странице |
| Всё остальное (записи, заказы, отзывы) | База данных на сервере | Это общие и важные данные |

## Безопасность на стороне страницы

- Все тексты от пользователей (имена, отзывы) перед показом **экранируются** функцией `esc()` —
  это защита от внедрения чужого кода (XSS). Если кто-то напишет в отзыве `<script>`,
  это покажется просто текстом.
- Страница **ничего не решает сама**: цены, свободное время, права администратора проверяет сервер.
