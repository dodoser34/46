## Самое главное за одну минуту

- **Blind Barber** — сайт сети барбершопов в Алматы, Астане и Костанае.
- Посетитель может **найти барбершоп**, посмотреть мастеров и отзывы, **записаться онлайн**
  на конкретное время и **купить средства для ухода** в интернет-магазине.
- Есть **личный кабинет** (мои записи, заказы, избранное) и **панель администратора**
  (все записи и заказы, смена статусов).
- Сайт состоит из двух частей:
  - **фронтенд** — то, что видно в браузере (HTML, CSS, JavaScript);
  - **бэкенд** — сервер на языке Python (фреймворк FastAPI), который хранит данные
    в базе SQLite и проверяет все действия.
- Основные сценарии проверяются автоматическими тестами и в браузере на настольном и мобильном размерах. Результаты — в [отчёте о проверке](07-тестирование/03-готовность-проекта.md).
