# Словарь терминов простыми словами

## Самые базовые слова

Если вы никогда не программировали — начните с этой таблицы. Подробно, с примерами из проекта,
всё это объяснено в [азбуке](../00-азбука/01-что-такое-программа-и-код.md).

| Термин | Простыми словами |
|---|---|
| **Программа** | Список указаний для компьютера, который он выполняет строчка за строчкой |
| **Код** | Текст программы, записанный на языке программирования |
| **Язык программирования** | Строгий язык, понятный компьютеру: Python, JavaScript |
| **Переменная** | Коробка с наклейкой-именем, в которой лежит значение: `price = 12000` |
| **Присваивание** | Положить значение в переменную. Знак `=` значит «положить», а не «равно» |
| **Значение** | То, что лежит в переменной: число, текст, «да/нет» |
| **Константа** | Переменная, которую не меняют. Пишется БОЛЬШИМИ буквами: `DELIVERY_FEE = 1500` |
| **Тип данных** | Вид значения: число, строка, логическое, список, словарь |
| **Число (int / float)** | Целое (`60`) или дробное (`4.9`) число |
| **Строка (string, str)** | Текст в кавычках: `"Алматы"`. `"60"` в кавычках — это текст, а не число |
| **Логическое значение (bool)** | Только два варианта: `True` (да) или `False` (нет) |
| **None / null** | «Пусто», значения нет |
| **Список / массив** | Несколько значений по порядку: `["Алматы", "Астана"]`. Нумерация с нуля |
| **Словарь / объект** | Пары «название → значение»: `{"time": "13:00", "available": true}` |
| **Функция** | Рецепт с названием: описали один раз, вызываем по имени сколько угодно раз |
| **Параметр / аргумент** | Что передаётся в функцию: `delivery_fee("courier", 8000)` |
| **return (вернуть)** | Результат, который функция отдаёт обратно |
| **Вызов функции** | Использование функции: имя и скобки, `formatPrice(12000)` |
| **Условие (if / else)** | Развилка: «если так — делай одно, иначе — другое» |
| **Цикл (for / while)** | Повторение: «для каждого товара…», «пока не закрылся барбершоп…» |
| **Исключение (raise / throw)** | Сознательная остановка с сообщением об ошибке: «время занято» |
| **try / except (catch)** | «Попробуй, а если не получится — сделай вот это» |
| **Класс** | Чертёж: какие поля есть у всех пользователей, товаров, записей |
| **Объект (экземпляр)** | Конкретная вещь по чертежу: один пользователь, один заказ |
| **Атрибут (поле, свойство)** | Одна характеристика объекта: имя, цена, телефон |
| **Метод** | Функция, которая принадлежит классу или объекту |
| **Импорт** | Подключение кода из другого файла: `from app.core.security import hash_password` |
| **Библиотека** | Готовый чужой код, который можно подключить и использовать |
| **Зависимость** | Библиотека, без которой проект не работает. Список — `backend/requirements.txt` |
| **Комментарий** | Пояснение в коде для людей. Компьютер его пропускает. В Python после `#`, в JS после `//` |
| **Синтаксис** | Правила записи языка: где скобки, кавычки, двоеточия |
| **Баг** | Ошибка в программе: работает не так, как задумано |
| **Отладка** | Поиск и исправление ошибок |
| **Тест / автотест** | Программа, которая проверяет другую программу |
| **assert** | Команда в тесте «убедись, что это правда» |
| **Клиент** | Тот, кто отправляет запрос. Обычно браузер |
| **Запрос / ответ** | Сообщение браузера серверу и то, что сервер прислал обратно |
| **URL** | Адрес в интернете: `http://localhost:5500/pages/shop.html` |
| **Домен** | Имя сайта в адресе: `example.com` |
| **Таблица / строка / столбец** | Части базы данных: тема / одна запись / одно поле |
| **Первичный ключ (id)** | Уникальный номер строки в таблице |
| **Внешний ключ** | Ссылка на строку другой таблицы: `master_id` в записи указывает на мастера |
| **Индекс** | «Оглавление» таблицы для быстрого поиска. Уникальный индекс ещё и запрещает дубли |
| **Транзакция** | Несколько изменений в базе, которые сохраняются все вместе или не сохраняются вовсе |
| **commit / rollback** | В базе: «сохранить изменения» / «отменить изменения» |
| **Терминал (консоль)** | Окно, где команды пишут текстом, а не мышкой |
| **Git** | Программа, которая хранит историю изменений проекта |

## Остальные термины

| Термин | Простыми словами |
|---|---|
| **Адаптивная вёрстка** | Сайт сам перестраивается под ширину экрана: телефон, планшет, компьютер |
| **Анимация** | Плавное изменение элемента: появление, сдвиг, поворот |
| **API** | «Окошко» сервера, через которое сайт просит данные или действие. Набор адресов `/api/...` |
| **Авторизация** | Проверка «кто ты и что тебе можно» |
| **Аутентификация** | Вход по логину и паролю — доказательство, что это ты |
| **Бэкенд** | Серверная часть: то, что работает «за кадром» (у нас — Python + FastAPI) |
| **База данных (БД)** | Хранилище информации в виде таблиц (у нас — SQLite, файл `barber.db`) |
| **Браузер** | Программа для просмотра сайтов: Chrome, Edge, Safari, Firefox |
| **Бургер-меню** | Кнопка из трёх полосок на телефоне, открывающая меню |
| **Валидация** | Проверка, что данные правильные (телефон из цифр, email с @) |
| **Виртуальное окружение (.venv)** | Отдельная папка с библиотеками только для этого проекта |
| **Деплой** | Размещение сайта в интернете |
| **Docker** | Упаковка программы в «контейнер», который одинаково запускается везде |
| **Endpoint (эндпоинт)** | Один адрес API, например `/api/bookings` |
| **FastAPI** | Фреймворк на Python для создания API |
| **Фреймворк** | Набор готовых инструментов и правил, на которых пишут программу |
| **Фронтенд** | Часть сайта, которую видит пользователь в браузере (HTML, CSS, JS) |
| **Хэш** | «Отпечаток» данных: из пароля получается строка, по которой пароль нельзя восстановить |
| **HTML** | Язык разметки: описывает, *что* есть на странице |
| **CSS** | Язык оформления: описывает, *как* это выглядит |
| **JavaScript (JS)** | Язык программирования в браузере: описывает *поведение* страницы |
| **HTTP / HTTPS** | Протокол общения браузера и сервера. HTTPS — то же, но с шифрованием (замочек) |
| **JSON** | Текстовый формат данных: `{"name": "The Cut", "rating": 4.9}` |
| **Кэш браузера** | Сохранённые копии файлов сайта, чтобы грузить быстрее. Обновить без кэша — Ctrl+F5 |
| **localhost** | «Этот компьютер». Адрес сайта, запущенного у вас локально |
| **localStorage** | Небольшое хранилище в браузере (у нас — корзина и токен входа) |
| **Медиазапрос** | Правило CSS «если экран уже 640 px — сделай так» |
| **Модуль** | Отдельный файл кода со своей задачей, который подключается в другие |
| **ORM** | Способ работать с таблицами базы как с объектами в коде (у нас — SQLAlchemy) |
| **Параллакс** | Эффект глубины: слои картинки двигаются с разной скоростью |
| **PBKDF2** | Надёжный алгоритм хэширования паролей с многократным повторением |
| **Порт** | «Номер двери» программы на компьютере. Наш сервер — порт 8000 |
| **Pydantic** | Библиотека проверки данных в Python |
| **pytest** | Программа для запуска автотестов на Python |
| **Python** | Язык программирования, на котором написан сервер |
| **Репозиторий** | Папка проекта с историей изменений (например, на GitHub) |
| **REST** | Стиль построения API: ресурсы + методы GET/POST/PATCH/DELETE |
| **Роутер** | Часть сервера, которая отвечает за группу адресов (записи, магазин, админка) |
| **Seed (сид)** | Начальное наполнение базы демо-данными |
| **Сервер** | Программа (или компьютер), которая отвечает на запросы |
| **Слот** | Отрезок времени для записи (у нас — начало каждого часа) |
| **Slug** | Короткое имя латиницей для адресов: «Алматы» → `almaty` |
| **Соль** | Случайная добавка к паролю перед хэшированием |
| **Спрайт** | Один файл, в котором собраны все иконки |
| **SQL** | Язык запросов к базе данных |
| **SQL-инъекция** | Атака: попытка выполнить свою команду в базе через поле ввода |
| **SQLAlchemy** | Библиотека для работы с базой данных из Python |
| **SQLite** | База данных в одном файле, без отдельного сервера |
| **Статус-код** | Число в ответе сервера: 200 — успех, 404 — не найдено, 409 — конфликт и т.д. |
| **SVG** | Векторный формат картинок: чёткий при любом размере |
| **Токен** | Случайная строка-«пропуск», которую сервер выдаёт после входа |
| **Uvicorn** | Программа, которая запускает FastAPI как веб-сервер |
| **Шторка (переход)** | Тёмный экран с логотипом, который плавно закрывает и открывает страницу при переходе |
| **XSS** | Атака: попытка вставить вредный скрипт на страницу через текст (например, отзыв) |
