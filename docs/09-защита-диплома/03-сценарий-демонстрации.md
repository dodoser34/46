# Сценарий демонстрации (3–4 минуты)

Подготовка: сайт запущен, база свежая (можно удалить `backend/data/barber.db` и перезапустить),
в браузере открыты вкладки: главная сайта и `http://localhost:8000/docs`.

| № | Действие | Что сказать |
|---|---|---|
| 1 | Обновить главную страницу | «Это главная страница. Главный экран собран из слоёв, поэтому при движении мыши появляется глубина» — подвигать мышью |
| 2 | Выбрать город «Алматы», услугу «Фейд» → стрелка | «Поиск по городу и услуге» |
| 3 | На странице барбершопов нажать «Рядом со мной» | «Сайт определяет местоположение и сортирует по расстоянию» (если браузер спросит — разрешить) |
| 4 | Открыть **The Cut** | «Страница барбершопа: фото, услуги, мастера, отзывы, контакты» — пролистать вкладки |
| 5 | Справа: услуга «Стрижка», мастер «Данияр», завтрашний день | «Сайт показывает только свободное время. Зачёркнутое — уже занято» |
| 6 | Выбрать время → «Продолжить» → имя и телефон → «Записаться» | «Запись создана, номер записи» |
| 7 | Вернуться назад и выбрать **то же время** | «Это время теперь недоступно — **система не допускает двойную запись**» |
| 8 | Магазин → добавить два товара | «Товар добавляется в корзину» (обратить внимание на анимацию) |
| 9 | Корзина → выбрать «Курьер» | «Доставка считается автоматически: до 30 000 ₸ — платная» → оформить |
| 10 | Вход → `admin@barber.kz` / `admin123` → «Панель администратора» | «Администратор видит все записи и заказы» — найти свою запись, сменить статус на «Подтверждена» |
| 11 | `F12` → режим телефона | «Сайт адаптирован под телефон» — показать меню-бургер |
| 12 | Вкладка `/docs` | «Сервер предоставляет документированное REST API — 31 адрес» |
| 13 | (по желанию) окно с тестами `scripts/test.ps1` | «24 автотеста проходят» |

## Если спросят «а покажите в коде»

| Что спросили | Какой файл открыть |
|---|---|
| Как считается свободное время | `backend/app/modules/booking/service.py`, функция `compute_slots` |
| Как защищены пароли | `backend/app/core/security.py` |
| Как проверяются права админа | `backend/app/shared/dependencies.py`, функция `get_admin` |
| Какие таблицы в базе | `backend/app/modules/` |
| Как проверяется телефон | `backend/app/shared/validation.py`, функция `check_phone` |
| Как страница получает данные | `frontend/assets/js/core/api.js` |
| Как сделана адаптация | `frontend/assets/css/responsive.css` |
| Как сделаны анимации | `frontend/assets/js/components/motion.js` |
| Тесты | `backend/tests/test_api.py` |
