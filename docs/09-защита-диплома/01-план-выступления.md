# План выступления на защите (7–10 минут)

Текст можно говорить почти дословно. В скобках — что показать на экране.

---

## 1. Вступление (30 сек)

«Здравствуйте. Тема моей дипломной работы — **разработка веб-сервиса онлайн-записи в барбершопы
с интернет-магазином средств для ухода**. Проект называется **Blind Barber**.»

*(Открыта главная страница сайта.)*

## 2. Актуальность и проблема (1 мин)

«Сейчас в большинство барбершопов записываются по телефону или через мессенджеры. Это отнимает время
у клиента и у мастеров, бывают ошибки и двойные записи на одно время, а клиенту трудно сравнить
барбершопы и мастеров между собой.

**Цель работы** — создать веб-сервис, где клиент может найти барбершоп, выбрать мастера,
увидеть реально свободное время и записаться онлайн, а также купить средства для ухода.»

## 3. Задачи (30 сек)

«Для достижения цели я решил следующие задачи:
1. проанализировал предметную область и аналоги;
2. спроектировал архитектуру и базу данных;
3. разработал серверную часть на Python и FastAPI;
4. разработал клиентскую часть на HTML, CSS и JavaScript с адаптацией под телефоны;
5. реализовал алгоритм расчёта свободного времени и защиту от двойной записи;
6. протестировал систему автотестами.»

## 4. Технологии и архитектура (1,5 мин)

*(Показать схему из [03-устройство/01-общая-схема.md](../03-устройство/01-общая-схема.md) или слайд.)*

«Система построена по архитектуре **клиент–сервер**.
- **Клиент** — сайт на HTML, CSS и чистом JavaScript, без тяжёлых фреймворков.
- **Сервер** — Python и FastAPI. Он предоставляет **REST API** из 31 адреса.
- **База данных** — SQLite, работа с ней через ORM SQLAlchemy. 14 таблиц.

Сервер разделён на слои: роутеры принимают запросы, схемы Pydantic проверяют данные,
сервисы содержат бизнес-логику, модели описывают таблицы. Такое разделение упрощает поддержку
и позволяет в будущем подключить мобильное приложение к тому же API.»

## 5. Демонстрация (3–4 мин)

*(Сценарий — в [03-сценарий-демонстрации.md](03-сценарий-демонстрации.md).)*

Коротко: главная → каталог с фильтром «Рядом со мной» → барбершоп → запись →
попытка записаться на то же время (запрещено) → магазин и заказ → панель администратора → телефон.

## 6. Ключевые решения (1 мин)

«Хочу отметить несколько важных решений:
- **Алгоритм свободного времени** учитывает часы работы, длительность услуги и существующие записи.
  Перед сохранением время проверяется повторно — это исключает двойную запись.
- **Безопасность**: пароли хранятся только в виде хэша PBKDF2 с солью, доступ по токенам,
  права администратора проверяются на сервере, цены считает только сервер.
- **Удобство**: адаптивная вёрстка под любые экраны, анимации, которые отключаются для людей,
  которым они мешают.
- **Качество**: автоматические тесты покрывают основные сценарии, параллельные запросы, склад и команды запуска; интерфейс дополнительно проверен в браузере.»

## 7. Итоги и развитие (30 сек)

«В результате создан работающий веб-сервис, который решает поставленную задачу.
В дальнейшем планируется: онлайн-оплата, SMS- и Telegram-уведомления о записи,
мобильное приложение на основе того же API, личный кабинет мастера.

Спасибо за внимание, готов ответить на вопросы.»

## Советы

- Запустите сайт **заранее**, до начала защиты, и проверьте по [чек-листу](../07-тестирование/02-ручная-проверка.md).
- Откройте нужные вкладки заранее: главная, `/docs`, панель администратора (уже войдя).
- Если что-то пошло не так во время показа — спокойно скажите «покажу на другом примере» и продолжайте.
- Главная фишка, которую стоит показать обязательно, — **защита от двойной записи**.
