# Blind Barber — онлайн-запись в барбершопы

> **Хотите понять проект целиком?** Прочитайте [ПРОЕКТ-ПРОСТЫМИ-СЛОВАМИ.md](ПРОЕКТ-ПРОСТЫМИ-СЛОВАМИ.md): что это, как устроено и почему сделано именно так. Основы программирования (переменная, функция, сервер, база данных) — в [азбуке](docs/00-азбука/01-что-такое-программа-и-код.md).

> **Скачали проект впервые?** Начните с [подробной инструкции ЗАПУСК.md](ЗАПУСК.md): что скачать, как установить Python, почему в Git нет `.env`, `.venv` и базы, как запустить сайт и исправить частые ошибки.

> **Подробная документация простым языком** — в папке [docs/](docs/README.md): как всё устроено, как запустить, вопросы и ответы для защиты.

> **HTML, CSS, JavaScript и Python:** [учебное руководство по исходникам проекта](docs/11-технологии/README.md). [Проверка готовности](docs/07-тестирование/03-готовность-проекта.md).

Дипломный проект: веб-сервис для поиска барбершопов, онлайн-записи к мастеру
и интернет-магазин средств для ухода.

- **Фронтенд:** HTML, CSS, чистый JavaScript (ES-модули, без фреймворков и сборщиков)
- **Бэкенд:** Python 3.11, FastAPI, SQLAlchemy 2, SQLite
- **Деплой:** Docker / docker-compose, Render, VPS (nginx + systemd)

## Возможности

| Раздел | Что умеет |
|---|---|
| Весь сайт | Живой фон (плавающие пятна света, зерно плёнки, линии сетки) — только CSS |
| Анимации | Появление блоков и «выезжающие» слова заголовков при прокрутке, заставка главного экрана, счётчики, наклон карточек с бликом, магнитные кнопки, курсор-кольцо, волна при нажатии, прогресс прокрутки, прячущаяся шапка, «моргающий» логотип, полёт товара в корзину, искры при записи/заказе/избранном, переход между страницами «шторкой» с логотипом. Всё отключается при системной настройке «уменьшить движение» |
| Главная | Многослойный главный экран с параллаксом, нестандартная композиция (лестница шагов, бенто, наложения, бегущая строка), поиск по городу и услуге, популярные барбершопы, услуги, промо магазина, подписка на новости |
| Барбершопы | Фильтр по городу, поиск, «Рядом со мной» (геолокация + расстояние), рейтинг, «Открыто сейчас», избранное |
| Страница барбершопа | Галерея с просмотром фото, услуги, мастера, отзывы (с пересчётом рейтинга), контакты, быстрая запись с выбором даты и времени |
| Мастер | Профиль, специализация, портфолио работ, отзывы, запись к мастеру |
| Запись | Мастер из 4 шагов: услуга → мастер → дата и время → подтверждение. Сервер проверяет занятость и не даёт записаться дважды на одно время |
| Магазин | Категории, поиск, сортировка, карточка товара, корзина, оформление заказа (самовывоз / курьер). Цены и остатки сервер берёт только из базы |
| Личный кабинет | Профиль, мои записи (отмена), заказы, избранное |
| Администратор | Сводка, все записи и заказы с фильтрами и сменой статуса |

Архитектура — **модульный монолит**: код каждой предметной области собран вместе. [Границы модулей и примеры изменений](docs/03-устройство/03-модули.md).

## Быстрый старт (Windows)

Установите **Python 3.11+** (при установке отметьте **Add Python to PATH**).
Откройте папку проекта в проводнике и дважды нажмите **START.cmd**.
Сразу запустятся фронтенд и бэкенд. При первом запуске зависимости установятся автоматически; нужен интернет.
Дождитесь надписи **ГОТОВО** и откройте http://localhost:5500.

| Файл | Что запускает | Адрес |
|---|---|---|
| `START.cmd` | Весь проект: два отдельных сервера | http://localhost:5500 |
| `frontend/start.cmd` | Только фронтенд | http://localhost:5500 |
| `backend/start.cmd` | Только бэкенд (API) | http://localhost:8000/docs |
| `backend/setup.cmd` | Установка / обновление зависимостей, включая тесты | — |

Для раздельного запуска откройте PowerShell в папке `backend` и выполните `.\start.cmd`.
Во втором терминале в папке `frontend` также выполните `.\start.cmd`.
Фронтенд раздаёт HTML/CSS/JS, а запросы `/api` пересылает на бэкенд (порт 8000).
Для входа, каталога, записей и заказов нужны оба сервера. Node.js и настройка CORS не требуются.
Оставляйте окна открытыми; остановка — **Ctrl+C** в соответствующем окне.

Из корня проекта: `.\START.cmd` для всего проекта или `.\backend\start.cmd` / `.\frontend\start.cmd` для отдельных серверов.
Подробности и решение проблем — [инструкция по запуску](docs/02-запуск/01-запуск-на-компьютере.md).

Linux / macOS: `python3 scripts/dev/launcher.py all` (или `frontend` / `backend` для раздельного запуска).
Прежние `scripts/run.ps1` и `sh scripts/run.sh` используют тот же общий запуск: сайт на 5500, API на 8000.

## Тесты

```bash
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

Автотесты проверяют запуск из папок frontend/backend и корня, отдельный сервер фронтенда и пересылку запросов API, регистрацию и вход, фильтры каталога, сортировку по расстоянию,
избранное, отзывы, свободные слоты, защита от двойной записи, отмена записи, заказы
(серверные цены, доставка), права администратора. Дополнительно проверяются конкурирующие запросы, возврат остатков при отмене, восстановление заказов и записей, расчёт выполненных заказов, проверка форм и ответы 404. [Состав и запуск тестов](docs/07-тестирование/01-автотесты.md).

## Бренд и иконки

- **Логотип** — `frontend/assets/img/brand/`: арка барбер-зеркала, внутри закрытый глаз («blind»),
  ресницы которого — зубья расчёски, сверху искра. Версии: горизонтальная (`logo.svg`, `logo-dark.svg`
  для светлого фона), вертикальная (`logo-vertical.svg`), отдельный знак (`mark.svg`), иконка приложения.
  В шапке и подвале логотип встроен в страницу (`components/logo.js`) и использует шрифт сайта.
- **Фавикон** — `frontend/assets/img/favicon.svg`, манифест — `frontend/site.webmanifest`.
- **Иконки интерфейса** — `frontend/assets/img/icons/*.svg` (24×24, линия 1.6). Сайт берёт их из спрайта
  `sprite.svg`. После добавления или правки иконки пересоберите спрайт:

```bash
backend/.venv/Scripts/python scripts/build_icons.py
```

## Фотографии

Изображения сайта (70 штук) находятся в `frontend/assets/img/`. Если отдельный файл недоступен, используется тёмная подложка.
Главные экраны собраны из слоёв: фон `.jpg` + отдельные фигуры `.webp` с прозрачным фоном (для эффекта глубины). WebP весит в 5–10 раз меньше PNG, поэтому страницы грузятся быстро.
Чтобы заменить фото, положите свой файл с тем же именем в ту же папку.

## Деплой

Всё подготовлено: Render (сайт + PostgreSQL по `render.yaml`), Docker (`docker-compose.yml` / `docker-compose.postgres.yml`) и VPS одной командой `sudo bash deploy/vps/install.sh домен почта`.
Пошагово: [docs/08-деплой/02-инструкция-по-деплою.md](docs/08-деплой/02-инструкция-по-деплою.md), чек-лист: [docs/08-деплой/03-быстрый-чек-лист.md](docs/08-деплой/03-быстрый-чек-лист.md): Docker, Render (бесплатно, по ссылке из GitHub) и VPS.

## Основные эндпоинты API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | Регистрация и вход (Bearer-токен) |
| GET | `/api/barbershops` | Список с фильтрами `city`, `q`, `sort`, `open_now`, `favorites`, `lat`/`lng` |
| GET | `/api/barbershops/{id}` | Барбершоп с мастерами |
| GET | `/api/masters/{id}/slots?date=&service_id=` | Свободное время мастера |
| POST | `/api/bookings` | Создать запись |
| GET | `/api/products` | Товары: `category`, `q`, `sort`, `ids` |
| POST | `/api/orders` | Оформить заказ |
| GET | `/api/admin/summary` | Сводка для администратора |

Полный список с примерами — в Swagger: `/docs`.
