# Фронтенд

HTML — в `index.html` и `pages/`. Стили, JavaScript, изображения — в `assets/`.

Из этой папки:

```powershell
.\start.cmd
```

Сайт: http://localhost:5500. Для данных и входа запустите бэкенд в другом терминале.
Node.js и npm не требуются. Локальный сервер и прокси `/api` находятся в `../scripts/dev/`.
